Lesson 1 of the numerical walkthrough

Next year’s premium

You are valuing a claim. The return you require this year is 3% plus the equity premium. To say what you will require next year, you only need next year’s premium. That is the whole lesson.

The rule

Call this year’s equity premium \(\lambda\). Next year’s expected premium is

$$ 0.03 + 0.50 \times \lambda. $$

One number in. One number out. Nothing else (no growth, no cash, no curve).

If the premium is already 6%

Plug in \(0.06\):

$$ 0.03 + 0.50 \times 0.06 = 0.06. $$

Next year’s expected premium is still 6%. The premium does not move. That is all “typical year” means here: 6% is the number the rule leaves alone.

Check: an AR(1) \(x_{t+1}=c+\phi x_t\) has rest point \(c/(1-\phi)\). Here \(0.03/(1-0.50)=0.06\). See Hamilton (1994), Time Series Analysis; and this derivation of the rest point \(a/(1-b)\).

If this year’s premium is 3%

Plug in \(0.03\):

$$ 0.03 + 0.50 \times 0.03 = 0.045. $$

Next year’s expected premium is 4.5%. The 0.50 is the weight on this year’s premium, not “keep half of 6%.”

Repeat, then plot

Start at 3%. Apply the same rule to the answer, then again. That list is the path.

lam = 0.03
path = [lam]
for _ in range(10):
    path.append(0.03 + 0.50 * path[-1])
# 3.00, 4.50, 5.25, …, 6.00

Plot path. Draw a dashed line at 6%. You should see the premium walk from 3% toward 6%.

import matplotlib.pyplot as plt
import numpy as np
years = np.arange(len(path))
plt.plot(years, 100 * np.array(path), "o-")
plt.axhline(6.0, ls="--")

Stop

This lesson is only the premium. Growth is a different number. It is not in the rule above. Ask before we add it.

Primary source: Hamilton, J. D. (1994). Time Series Analysis. Princeton University Press. AR(1) with intercept.
